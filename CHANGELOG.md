# What's New

## 0.4.0 — 2026-11-22T06:29Z

Builder can publish a sermon's notes straight to the site

- Builder publishes one sermon per date. If a sermon or draft already uses that date, Builder stops instead of replacing it.
- If Builder sends the same notes again, it gets the same link without changing the sermon or creating a copy.
- Each sermon's public link is permanent: `/sermons/<id>`.
